# Changelog

## [0.9.2] — 2026-10-14

### Добавлено
- Автопродление access-токена в фоне.
- Чекбокс «Запомнить меня на 7 дней» на экране входа.
- Разделение учётных записей: каждый пользователь видит только свои карты.
- Диалог миграции локальных карт при первом входе в аккаунт.
- `remember_me` — долгая сессия по требованию.

### Исправлено
- Картинки карт синхронизируются между устройствами.
- Локальная картинка больше не затирается при sync, если сервер вернул null.
- Сброс cooldown синхронизации после успешного sync.
- Диалог «Привязать локальные карты?» больше не показывается повторно.

### Улучшено
- Валидация длины полей карты (name — 100, about — 255, barcode — 100).
- Кнопка logout вызывает серверный `/auth/logout`.

## [0.9.0] — 2026-10-13
